# GUPPSHUPP - Founding AI Engineer Assignment

This project implements:
- A Memory Extraction Module
- A Personality Engine
- Before/After personality response demo
- Simple UI + API

## 🚀 How to Deploy (No Coding Needed)

### 1. Create a GitHub Repo  
Upload all project files exactly as provided.

### 2. Deploy to Render
- Go to https://render.com
- Create → Web Service
- Connect GitHub repo
- Select:
  - Runtime: **Docker**
- Deploy!!

### 3. After deployment, visit your live link.
- Upload 30 messages
- Choose personality
- See memory extraction + transformed replies
